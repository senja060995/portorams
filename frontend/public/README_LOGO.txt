=====================================================
    PT. RAGAM MANFAAT SINERGI (RAMS) - LOGO ASSET GUIDE
=====================================================

Untuk mengganti logo website dengan logo Anda sendiri:

1. Simpan file logo Anda di folder ini:
   Path: /Users/sidomulyo/PT RAGAM MANFAAT SINERGI/portofoliorams/frontend/public/

2. Beri nama file logo Anda:
   - logo.png   (Logo format PNG transparan)
   - logo.svg   (Logo format SVG vektor)
   - favicon.ico (Icon tab browser)

3. Setelah file disimpan di folder public, logo dapat dipanggil di kode HTML / Next.js dengan path:
   <img src="/logo.png" alt="RAMS Logo" />
